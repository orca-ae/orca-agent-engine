# Governance

This page describes how Orca Agent Engine is run.

## Maintainers

The maintainers are the code owners listed in [CODEOWNERS](.github/CODEOWNERS) and in
[MAINTAINERS.md](MAINTAINERS.md). They review and merge pull requests, triage issues and
discussions, and handle security and conduct reports.

## How decisions are made

- Decisions happen in public: on the pull request or issue they concern, or in
  [GitHub Discussions](https://github.com/orca-ae/orca-agent-engine/discussions).
- A pull request merges when a maintainer approves it and CI passes.
- Maintainers decide by consensus on the pull request. When a maintainer raises an objection, the
  change waits until the objection is resolved there.
- An Orca Improvement Proposal (OIP) is accepted with approvals from two maintainers, at least one
  of whom owns an area the OIP changes, and no unresolved objection from a maintainer. Merging its
  pull request accepts it. [`proposals/README.md`](proposals/README.md) describes the process.

## Adding maintainers

There is no formal process for adding maintainers.

## Changing this document

Changes to this page go through a pull request, like any other change.
