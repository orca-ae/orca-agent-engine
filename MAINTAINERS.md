## What maintainers do

- **Review and merge pull requests.** Every pull request needs a maintainer's approval before it
  merges.
- **Triage** issues and discussions: label them, answer questions, and close duplicates.
- **Keep `main` healthy:** CI passing, and documentation that matches the code.
- **Handle private reports:** security vulnerabilities, as described in [SECURITY.md](SECURITY.md),
  and conduct reports, as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- **Cut releases.**

[GOVERNANCE.md](GOVERNANCE.md) describes how maintainers make decisions.
